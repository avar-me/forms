# Avar Forms — правила для Claude

## Главный принцип

**forms.avar.me только анализирует данные из sources.avar.me — ничего не исправляет и не добавляет от себя.**

Все источники в `config/sources.json` проверены администраторами sources.avar.me.
Правки орфографии, написания, смысла — только в самих источниках (репозиторий `sources`).
Этот репозиторий — только код агрегации и маппинга.

## Что должно быть в индексе

Все словоформы из верифицированных источников должны:
- попадать в `output/wordforms.csv` (быть доступны для поиска на сайте)
- попадать в `output/lemma_frequencies.csv` (частотный список)

Словоформа может не маппиться на лемму av-ru словаря — это нормально. Она всё равно
должна быть в индексе с пустой леммой. Маппинг на лемму — дополнительная информация,
не условие попадания в список.

Фильтрация только одна: токен должен выглядеть как аварское слово (содержать палочку ӏ
или заканчиваться на признанное аварское окончание). Это нужно чтобы отсеять русские
слова и латиницу из аварских текстов. Прошедший фильтр токен включается всегда.

## Архитектура источников

- `config/sources.json` — список источников
- `avarforms/sources/` — экстракторы для каждого типа источника
- `mappings/gimbatov.overrides.json` — ручные уточнения маппинга (минимально)
- Данные скачиваются при сборке с sources.avar.me, в git не коммитятся

## Правки данных

Если слово написано неверно или отсутствует в словаре — это правится в sources.avar.me,
не здесь. Не добавлять словоформы вручную в код или маппинги ради исправления данных.
